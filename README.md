# Android_Development_CSE489

## Bigger Number Game

A small Android game built with Kotlin and Jetpack Compose.

- Two different random numbers (0–9) are shown on two cards.
- Tap the card with the bigger number: a correct guess earns a point, a wrong guess loses one.
- A "Correct!" / "Wrong!" message appears after each guess.
- Points never go below 0. Guessing wrong at 0 points shows a "Go learn math, you dumb!" pop-up.
- Reaching 10 points shows a "GENIUS!" pop-up with a Play Again button.

### Running it

Open the project in Android Studio, pick an emulator or a phone connected over USB, and press **Run**.
Requires Android 7.0 (API 24) or newer.
